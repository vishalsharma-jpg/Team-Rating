Firebase Setup Required — Replace the config below to enable live sync

1. Go to console.firebase.google.com → Create project → Add Web App → copy your config.
2. In the HTML file, find REPLACE_WITH_YOUR_* and paste your values.
3. In Firebase → Realtime Database → Rules, set both .read and .write to true → Publish.
4. Host on Netlify Drop and share the URL.
